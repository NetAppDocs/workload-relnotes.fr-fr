=== Prise en charge de plusieurs systèmes de fichiers pour une seule instance

Workload Factory for Databases prend en charge plusieurs systèmes de fichiers par instance Microsoft SQL Server. Vous pouvez enregistrer plusieurs systèmes de fichiers dans une instance SQL Server et corriger simultanément un problème de configuration pour plusieurs systèmes de fichiers dans une instance SQL Server.
