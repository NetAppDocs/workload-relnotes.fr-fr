=== Mise à jour du calculateur d'épargne

Vous pouvez comparer différents éléments de coût liés à l'exécution de charges de travail Microsoft SQL Server, tels que le stockage, le calcul, la licence SQL, les instantanés et les clones pour vos charges de travail de base de données sur les systèmes de fichiers FSx for ONTAP, par rapport à Elastic Block Store (EBS), FSx for Windows File Server et au stockage sur site, en utilisant uniquement les autorisations de consultation, de planification et d'analyse.
