=== Configurations de base de données incluses dans un tableau de bord bien architecturé

Le tableau de bord à l’architecture optimisée inclut désormais des recommandations pour les configurations de votre base de données, vous permettant d’évaluer et d’optimiser votre installation selon les meilleures pratiques. Les premières configurations affichées dans le tableau de bord sont :

* Hiérarchisation des données froides
* Efficacités du stockage
* Stratégie de snapshot
* marge de capacité SSD
* Gestion de l'espace des périphériques de blocs
* Type de OS
* Faire correspondre le type de système d'exploitation du périphérique de bloc à l'hôte
* Périphériques de bloc inactifs (LUNs)
* Placement des fichiers de données (.mdf)
* Emplacement des fichiers journaux (.ldf)
* État des E/S multipath
* Délai d'attente des E/S multivoies
* quorum du cluster
* Dimensionnement optimal des ressources de calcul


Sélectionnez le menu principal dans la console Workload Factory, puis sélectionnez *Well-architected* pour trouver le tableau de bord Well-architected.
